* To Create a Plugin follow the instructions mentioned in this url : https://github.com/dart-lang/native/blob/main/pkgs/jnigen/example/kotlin_plugin/README.md
* run flutter build apk in example
* set JavaSDK version to 21 sudo update-alternatives --config java
* Copy jnigen.yaml file and make changes according to your requirement
* Place this block
    kotlinOptions {
        jvmTarget = JavaVersion.VERSION_11.toString()
    }

    in android/build.gradle of Plugin
